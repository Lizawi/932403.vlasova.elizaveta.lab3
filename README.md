# Лабораторная работа №3. Flexbox и Grid

Персональная страница «О себе» в теме «Историк и реконструктор» (вариант 19).

## Что сделано
- Адаптивное flex-меню навигации
- Flex-карточки «Исторические эпохи» (3 шт., 3/2/1 колонка на десктопе/планшете/мобильном)
- Grid-сетка «Артефакты музея» (2×2, 1 колонка на мобильном)
- Медиа-запросы для планшетов и мобильных
- Семантические теги `<article>`, `<figure>`, `<time datetime="...">`

## Файлы
- `index.html` — разметка страницы
- `style.css` — стили
- `images/` — изображения

## Технологии
HTML5, CSS3 (Flexbox, Grid, медиа-запросы)
